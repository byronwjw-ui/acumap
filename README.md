# AcuPoint Atlas 穴位图谱

中文穴位科普静态网站，单文件运行。

## 使用方法

**本地预览**：直接双击 `index.html` 在浏览器打开即可。

**部署到 GitHub Pages**：
1. 进入仓库 Settings → Pages
2. Source 选择 `Deploy from a branch`
3. Branch 选择 `main` / `(root)`，保存
4. 等待几十秒，访问 `https://<用户名>.github.io/acumap/`

## 内容

- 首页（常见不适入口 + 热门穴位）
- 常见不适（胃部、头痛、肩颈、睡眠、焦虑、经期、腰背等）
- 穴位图谱（可筛选，含 20 个常用穴位）
- 经络入门（11 条经络）
- 安全按揉指南
- 安全须知 / 免责声明
- 搜索（hash 路由 `#/search?q=...`）

## 说明

本站仅用于穴位知识科普与健康教育，不提供诊断或治疗建议，不教授自行针刺。
